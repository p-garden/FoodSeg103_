## 🍽️ FoodSeg103: 음식 이미지 기반 재료 분석 모델 개발

### 1. 프로젝트 개요
본 프로젝트는 음식 이미지 기반 재료 분석 모델을 개발하는 것을 목표로 합니다. 음식  사진에 포함된 재료들을 픽셀 단위로 정확하게 분리하고 인식하는 Semantic Segmentation 기술을  활용하여, 건강 관리 및 식단 분석에 기여하고자 합니다.

### 2. 연구 배경 및 주제

* 본 연구는 CV의 하위 분야인 Semantic Segmentation을 적용합니다. 이 기술은 같은 범주에 속하는 픽셀들을 하나의 영역으로 묶어, "무엇이 어디에 있는지"를 세밀하게 파악합니다.
* 음식은 형태, 색상, 질감 등이 매우 다양하고 여러 재료가 한데 섞여 있는 경우가 많아, Semantic Segmentation을 적용하기에 적합한 주제입니다.

### 3. 데이터셋
* **데이터 크기**: 총 7,118장의 음식 이미지로 구성됩니다 (학습용 4,983장, 테스트용 2,135장). 각 이미지는 $384 \times 512$ 해상도의 RGB 이미지입니다.
* **클래스 수**: 총 104개 클래스 (103개 음식 클래스 + 1개 배경 클래스)로 이루어져 있습니다.
* **어노테이션**: 각 이미지에는 음식 영역이 픽셀 단위로 라벨링된 마스크가 포함되어 있습니다.
https://huggingface.co/datasets/EduardoPacheco/FoodSeg103

### 4. 모델 분석 및 최종 결과
다양한 Semantic Segmentation 모델을 비교 분석했습니다.
| Model | mIoU | acc |
| :--- | :--- | :--- |
| UperNet | 0.2822 | 0.7012 |
| DeepLabV3+ | 0.1757 | 0.6648 |
| PSPNet | 0.1902 | 0.6594 |
| **SegFormer** | **0.3816** | **0.7603** |
| **FiINAL SegFormer** | **0.4278** | **0.7873** |    

* **UperNet**: PPM(Pyramid Pooling Module)과 FPN(Feature Pyramid Network) 구조를 활용해 전역 문맥과 지역 디테일을 동시에 반영하지만, 여러 클래스에 걸쳐 찍는 경향을 보였습니다.
* **PSPNet**: Pyramid Pooling을 통해 크기 차이가 큰 재료도 잘 분리하고 전역적 맥락을 활용하지만, 세밀한 경계 처리 능력에 한계가 있었습니다.
* **DeepLabv3+**: Atrous Convolution을 활용해 경계 처리 능력을 강화했으나, 데이터셋과 실험 세팅의 한계로 인해 경계 처리 능력이 약하게 나타났습니다.
* **SegFormer**: Transformer 기반의 최신 모델로, 다른 모델들보다 가장 높은 성능(mIoU 0.3816, acc 0.7603)을 보이며 우수한 예측 능력을 증명했습니다.

최종 모델로는 **SegFormer**를 선정하였고, 성능 개선을 위해 전처리 및 데이터 증강을 강화했습니다.
* **전처리 및 최적화**: 입력 이미지 크기를 (512, 512)로 조정하고, 가중치 규제(Weight Decay)와 AMP(Automatic Mixed Precision)를 도입했습니다.
* **데이터 증강**: `Albumentations` 라이브러리를 활용하여 무작위 크기 자르기, 수평 뒤집기, 색상 및 흐림 변형 등 다양한 변형을 적용했습니다.

이러한 개선을 통해 최종 모델의 성능은 **mIoU 0.43**, **mAcc 0.78**로 향상되었습니다.

### 5. 연구의 의의 및 시사점
* **연구의 의의**: 픽셀 단위로 음식의 위치와 경계를 판별하는 것이 가능해져, 색상이나 형태가 유사한 음식도 구분할 수 있게 되었습니다. 이는 실생활과 밀접한 AI 응용 가능성을 보여줍니다.
* **연구 시사점**: 음식 사진만으로 **영양 분석** 및 **칼로리 추정**이 가능해져, 개인 맞춤형 헬스케어 및 다이어트 관리 서비스로 확장될 수 있습니다. 또한, 배달/외식 플랫폼의 메뉴 분류, 푸드테크 분야의 자동 레시피 추천 등 다양한 분야에 응용될 수 있습니다.
